# 3D Parallax logo — layered P

A new brand mark for 3D Parallax: three overlapping planes create a bold P and suggest the extension's parallax backgrounds and movable elements. Deep evergreen, ivory and sage match the public website's palette. The original is a PNG generated using the built-in imagegen tool, with genuine transparency outside the rounded tile.

## Files

`logo-master.png` is the original high-resolution generated artwork. `logo-1024.png` and `logo-512.png` are larger exports. `icon16.png`, `icon32.png`, `icon48.png` and `icon128.png` are PNG exports for extension usage. The 128px export fits the artwork inside a centered 96px square, with at least 16px transparent padding on every side, following [Chrome's icon guidance](https://developer.chrome.com/docs/webstore/images).

The public website now uses this logo in its header, footer, favicon, social preview and software structured data. The submitted 2.5.0 extension ZIP and its bundled icons are unchanged. A future extension release can copy the appropriate files into `custom extension/icons`, retain the existing manifest paths, increment the manifest version, and build a new upload ZIP. Use the same icon on the store listing when adopting the branding there.

Exports preserve the original artwork and alpha; they only normalize padding and scale the raster. They are not editable vector files. Small versions use the same recognizable silhouette.

## Generation prompt

Use case: logo-brand.
Asset type: finished app icon and brand mark for the Chrome extension 3D Parallax, a personal new-tab homepage with layered wallpapers and movable widgets.
Create ONE polished, distinctive logo, not a presentation sheet. A bold geometric portal/P monogram built from three slightly offset rounded planes, suggesting parallax depth and stacked browser windows. Make the symbol feel carefully designed: strong recognizable silhouette, generous negative space, balanced optical alignment, confident simple geometry. Use the site's forest-green, charcoal and pale-sage palette: a deep evergreen rounded-square tile, a warm ivory front plane, and a mint/sage offset rear plane. The P should emerge from the geometry, without any separate lettering. A small amount of depth from overlapping flat color faces is enough; front-facing with only subtle perspective. Premium, calm, useful desktop software branding, clear even at 16px. No imitation of other companies' logos.
Composition: square 1024 by 1024 canvas; center the rounded-square icon tile within the middle 768 by 768 area, with approximately 128px fully transparent clear padding on all four sides. The symbol inside the tile should be large and bold, not tiny. Crisp vector-like edges and flat solid colors with very restrained shading at overlaps. Transparent pixels outside the rounded tile, no white or checkerboard background.
Constraints: no text, no brand name, no slogan, no tiny lettering, no watermark, no surrounding border, no drop shadow outside the tile, no extraneous sparkles, no neon rainbow gradients, no mockup devices, no glossy photorealistic 3D render. Return the single production logo by itself.
