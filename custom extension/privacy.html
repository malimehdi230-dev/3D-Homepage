Privacy Policy

Last updated: 2026-06-27  ·  Extension version: 2.1.0

1. What data we collect

3D Parallax New Tab does not collect, transmit, or share any personal data with us or any third party.

All settings (your name, theme preference, quick links, headline lines, wallpaper image, AI provider keys) are stored locally on your device only, using chrome.storage.local and localStorage. This data never leaves your browser.

2. Permissions we use — and why

  • storage / unlimitedStorage — saves your settings and wallpaper blob locally.
  • Geolocation (optional, browser-level prompt) — fetches weather from the public Open-Meteo API using your coordinates. Your coordinates are sent directly from your browser to Open-Meteo; we do not see or store them.

3. Third-party network requests

The extension may make the following outbound requests on your behalf:

  • Open-Meteo (api.open-meteo.com) — free, open-source weather API. No account or API key required. See their terms.
  • Groq API (api.groq.com) — used for the AI chat feature only when you provide your own API key and send a message. Your API key is stored locally and sent only to Groq's servers.
  • DuckDuckGo Instant Answer API — used for the AI web-search feature when toggled on.

No tracking pixels, analytics SDKs, or advertising networks are included.

4. AI provider keys

If you add a Groq API key (or any OpenAI-compatible key), it is stored in chrome.storage.local and never transmitted anywhere except directly to the provider's API endpoint when you send a chat message. You can delete any stored key at any time from the Settings panel inside the extension.

5. Children's privacy

This extension is not directed at children under 13. We do not knowingly collect information from children.

6. Changes to this policy

If we make material changes we will update the "Last updated" date above and bump the extension version. Continued use after an update constitutes acceptance of the revised policy.

7. Contact

For questions or concerns, open an issue on the GitHub repository.
